# 命令参考

全部子命令、选项与退出码。命令的行为机制见《工作原理与性能》，报错处理见《常见问题》。

## 子命令

```text
blocksync sync <输入目录> <输出目录> [--dry-run] [--full] [--verify]
      把输入目录增量镜像到输出目录；反向同步交换两个参数的顺序。
blocksync setup                交互录入或修改本机两个目录（首次必做）
blocksync setup --show         查看当前配置
blocksync status [<目录>]      查看该目录的索引覆盖情况
blocksync verify [<目录>]      全量重算哈希，检查磁盘内容与索引是否一致
blocksync repair [<目录>]      按磁盘实际内容重建索引
```

省略目录参数的命令（status/verify/repair）读取 `setup` 保存的本机配置；`sync` 始终要求显式给出两个目录。

## 选项

| 选项 | 说明 |
|---|---|
| `--dry-run` | 测试比对：逐文件报告状态与变化量并汇总读取/预计写入，不写数据文件、不更新索引（目标索引失效时仍会重扫目标以获得真实哈希，这部分读取会计入汇总） |
| `--verify` | 写入后复读校验：每写一个文件立即重读并重算哈希对照 |
| `--full` | 忽略修改时间，全部文件重读重算（源索引一律按失效处理） |
| `--workers N` | 单文件内部哈希并行度，默认 CPU 核数 |
| `--lb BYTES` / `--sb BYTES` | 粗块/细块大小，默认 4194304 / 32768；`LB > SB` 且 `LB % SB == 0`，两侧必须一致 |
| `--force` | 删除上次异常退出遗留的 `.blocksync\lock` 后接管 |
| `--yes` | 跳过首次同步与删除前的人工确认（脚本无人值守） |
| `--allow-mass-delete` | 删除数量超过安全上限（`max(100, 源文件总数 × 1%)`）时仍继续 |
| `--quiet` | 不输出逐文件进度行 |

选项写在位置参数前后均可（内部会先把选项挪到位置参数之前），`--选项=值` 与 `--选项 值` 两种写法都支持。

## 退出码

| 码 | 含义 |
|---|---|
| 0 | 成功（包括「已是最新」这类提前返回，都会走 0） |
| 1 | 失败：同步/校验出错、参数错误、用户取消确认 |
| 2 | 未给出或无法识别子命令（`--help` 正常输出并返回 0） |
